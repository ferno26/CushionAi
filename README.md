# Fox Pool Trainer

A fresh standalone, offline Android practice simulator for learning pool shot geometry. It does not modify, inspect, automate, or overlay another game.

## Features

- Manual drag-and-drop ball layouts
- Cue-ball, object-ball and combination-shot prediction
- Zero to four cushion rebounds and bank-shot visualization
- Deterministic equal-mass collision simulation
- Power and side-spin controls
- Full rack and randomized drills
- No login, network, screen-capture or overlay permissions

## Source and builds

The complete fresh project is in fox-pool-trainer-source.zip. GitHub Actions extracts it, runs deterministic physics tests, compiles against Android SDK 35, verifies the APK signature, and publishes Fox-Pool-Trainer-APK.
